## Восстановление и следующий переход

После захвата capture должен завершиться, а own voice processes вернуться к0;
voice.paused не снимается. Установленный app/ключи/конфиги сохраняются.
Изменять модель на Mini или открывать cloud input по удачному development
результату не планируется.

Следующая приёмка: новая unseen-проба → более длинные negatives/фон → один PCM
через matcher/wrapper/gate/runtime → ограниченный облачный вопрос. Слышимость,
drain/echo проверяются отдельно после восстановления динамика при выключенном
питании. Выбор голоса не требует менять правила активации/авторизацию tools.

Порядок и ссылки на голоса: [практический план](../plans/2026-11-05-wakeword-corpus-and-voices.md).

| 0,5 м | 2,20 | 16,60 / 17,5 дБ | 15,75 / 17,1 дБ |
| 2 м | 2,68 | 4,43 / 4,4 дБ | 4,30 / 4,1 дБ |

Падение контраста около 13 дБ наблюдалось для обеих форм в этом сеансе.
У `contextual2` совпали 2 из 2 окон вблизи и 1 из 2 вдали. У исходного
профиля совпало одно окно вблизи. Один повтор на форму и фиксированный
порядок «вблизи → вдали» ограничивают вывод. Следующая проверка
`contextual2` — дополнительные повторы с 2 м и длительный непрерывный фон
без подбора порогов по этому блоку.

Эталоны и probe сверены с сохранёнными SHA256. Манифесты, хеши PCM,
метрики и результаты хранятся приватно. Оба репозитория были dirty до
захвата. Post-check подтвердил `voice.paused=1`, `voice_processes=0`
и SHA256 приложения
`de2171b4ea29a671cd6e946178ffe790ee7a9e658a113f30f976594b1f7284cc`.

## Три повтора с 2 м

Три первые попытки исключены по просьбе владельца. Для четвёртой
захват стартовал после подтверждения готовности. Владелец ориентировался
на собственный 15-секундный отсчёт вместо ожидания сообщения в чате
и подтвердил все три пары в заданном порядке.

`farRepeats4` содержит 60 с PCM и 92 160 000 байт исходного RAW. Шесть
приближённых окон отмечены по AC RMS в 20-мс кадрах и заданному порядку
до просмотра детекций. Оценены 58 с после warmup с допуском 1,2 с после
окна. Профили сверены по SHA и повторены с зафиксированными порогами.

| Профиль | «Штучка», из 3 | «Слушай, Штучка», из 3 | События вне окон |
|---|---:|---:|---:|
| Исходное «Штучка», 0.60 / 0.50 | 0 | 0 | 0 |
| Эталон «Слушай, Штучка», 0.60 / 0.50 | 0 | 0 | 0 |
| `contextual2`, 0.50 / 0.25 | 1 | 0 | 0 |

Единственное попадание — первое «Штучка» на 7,280 с от начала захвата.
Ни у одного профиля не осталось незавершённого совпадения и не было
событий на дополненном нулями хвосте. Это отдельная контрольная запись
с одним участником в одной комнате. Текущая повторяемость с 2 м
недостаточна для приёмки. PCM, разметка и выход probe хранятся приватно.

## Пять минут непрерывного фона

По отдельному подтверждению владельца выполнен один захват на 300 с
без намеренных обращений. RAW по SSH передавался напрямую в stdin
анализатора на Mac. Аудиофайл не создавался. Сохранён один приватный
JSON со счётчиками, контрольными суммами и временами. Голосовой runtime
был на паузе, cloud, воспроизведение и HA в прогоне не участвовали.

В потоке один детектор `contextual2` с порогами 0.50 / 0.25,
Median, min_scores=5, eager=false. Анализатор применяет тот же Avg4,
трёхточечный FIR и сдвиг 16 бит, что минутный захват. Контрольный
прогон на сохранённом RAW парного опыта воспроизвёл все три смещения
срабатываний и ноль событий на хвосте. Три синтетических теста
анализатора прошли. Для runner проверены точный, оборванный и зависший
синтетические потоки. На Mini использованы встроенный предел захвата
и отдельный ограничитель по настенным часам, на Mac общий deadline 340 с.

- Получено ровно 460 800 000 байт RAW с EOF. Оба процесса завершились
  с кодом 0. Время прогона 301,19 с.
- После первых 2 с осталось 298 с PCM. На полные кадры пришлось
  **297,99 с, 0 срабатываний**. Последние 10 мс обработаны с дополнением
  в отдельной категории хвоста.
- На хвосте 0 срабатываний. Незавершённых совпадений на конце входа
  и хвоста нет. Ненулевые семплы подтверждают поступление сигнала.

Это результат одного фонового сеанса, без оценки суточной частоты
ложных активаций. Для применения на 2 м остаётся проблема пропусков
в положительном тесте.
