   - Все 83 модульных и интеграционных теста пакета `mini-assistant` завершились успешно (`83 passed, 0 failed`).

   - Скомпилирован статический ARM32 musl бинарник:
     - Целевая архитектура: `armv7-unknown-linux-musleabihf`.
     - Размер: 2.5 МБ (ELF 32-bit LSB executable, ARM, EABI5, statically linked, stripped).

3. **Калибровка порогов микрофона:**
   - В `/data/opt/mini-assistant/.env`:

     - Акустическая утечка из динамика в микрофон при воспроизведении (RMS ~240 при `MINI_MIC_GAIN=2.0`) больше не вызывает ложного самопрерывания (false barge-in).
     - Речь человека вблизи микрофонов (RMS 1000–5000+) надежно активирует намеренное прерывание («Штучка, стоп!»).

4. **Автономный supervisor и холодный старт:**
   - Создан скрипт супервизора `/data/opt/mini-assistant/run-supervisor.sh` с автоматическим перезапуском при сбое.
