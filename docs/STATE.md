# Состояние проекта

Обновлено: 2026-11-01. Этот файл — короткая точка входа, не замена evidence
и не подтверждение текущей доступности оборудования.

## Цель

Собственный голосовой ассистент на Mini 1 с использованием её процессора,
микрофонов и динамика; HA и Spotify; без сервисов и аккаунтов Яндекса.
Провайдеры диалога/STT/TTS остаются архитектурным выбором. Полная замена
штатного дистрибутива не выполнена и не нужна как условие каждого прототипа.

## Подтверждённое исследованием

- Mini: A113X, исследованный userspace ARM32/armhf, glibc 2.23, около 236 MiB RAM.
- Постоянный key-only root SSH на порту 2222 был настроен и проверен.
  Наличие/доступность сегодня проверяются отдельным preflight.
- В прежних звуковых опытах владелец подтвердил слышимость PCM-тестов.
- На 31.10 есть C/Python-прототип прямых Pi↔Mini control/audio каналов.
  Вывод цифровой тишины и одновременный обработанный mic input проверялись;
  вход на Pi отбрасывался в RAM. Это не завершённый речевой ассистент.
- Временные ключи/процессы исследовательских опытов удалялись; постоянную
  службу с reconnect эти опыты не устанавливали.
- В позднем инвентаре Raspberry определена как Pi 4B Rev1.4. Ранее в чате
  называлась Pi 5; не распространять эту старую гипотезу на новые измерения.

## Новая ветка реализации

`mini-assistant/` — отдельный Rust-репозиторий с Gemini Live, HA-клиентом и
аудиокодом. Его README описывает целевой продукт шире фактической готовности.
Наличие исходника/ключа в `.env` не доказывает запуск на Mini, рабочий Spotify,
полный диалог или отключение облака Яндекса. Реальный контракт уточнять по
коду и последним проверкам. Секреты в этот файл не переносить.

## Ближайший инженерный рубеж

Выбрать и проверить один полный путь: wake/VAD → input → выбранный backend →
output → cancel. Сначала зафиксировать интерфейсы, ABI, ресурсы и ошибки,
затем получить target build и ограниченный живой результат. HA и музыка
подключаются отдельными проверяемыми контрактами.

Общие правила и автоматические проверки workflow введены в корневой Git;
существующий репозиторий приложения сохранён. Решение о границах:
[ADR-0001](decisions/0001-repository-boundaries.md).
