# ADR-0001: сохранить независимый репозиторий приложения

- Дата: 2026-11-01
- Статус: принято для текущего рабочего пространства

## Контекст

В корне `gpt-mini` Git отсутствовал. В `mini-assistant/` уже были история
коммитов, локальные секреты и незавершённые пользовательские изменения.
Рядом лежат приватный лабораторный стенд и исследовательский архив.
Пользователь запросил общие правила агентов и коммит workflow в корне.

## Решение

Создать в корне отдельный Git для общих инструкций, решений, шаблонов и их
проверок. Исключить вложенный репозиторий приложения, приватные материалы
и старый исследовательский архив. Правила приложения и его CI коммитить
в существующем Git без посторонних изменений. Не создавать submodule,
не переносить `.git` и не переписывать историю.

## Альтернативы и последствия

Единый monorepo удобен для общего CI, но потребовал бы отдельной миграции
истории и отбора архива. Только вложенный Git не сохранял бы общие корневые
инструкции. Текущее решение сохраняет оба контекста; push и clone выполняются
раздельно, а локальные исследования не воспроизводятся из корневого clone.
При подготовке публикации можно отдельно решить, какие исходники и
обезличенные доказательства перенести под контроль версий.
